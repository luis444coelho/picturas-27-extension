# Requisitos Funcionais: UC-VID-001 — Recorte Temporal (*Trim*)
### PictuRAS (v27.1) · Fase 1: Suporte a Vídeo Digital

Estes requisitos especificam a operação de recorte temporal (*trim*): seleção dos pontos de início e fim, sincronismo com a posição corrente de reprodução (*scrubbing*), cálculo dinâmico de duração, validações de integridade temporal e geração do novo ficheiro MP4 (H.264/AAC) a partir de originais MP4, MOV ou AVI, com resolução e taxa de fotogramas preservadas.
