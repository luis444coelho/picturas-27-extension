# Requisitos Funcionais: UC-VID-006 — Descarregamento de Vídeo
### PictuRAS (v27.1) · Fase 1: Suporte a Vídeo Digital

Estes requisitos cobrem o descarregamento de vídeos do projeto para o dispositivo do utilizador: autorização por permissão de leitura, URLs assinados temporários, restrição a recursos concluídos, isenção de quota, nome de ficheiro sugerido, entrega no formato armazenado (nunca a cópia de pré-visualização) e retoma de transferências interrompidas.

---

| **ID** | **Requisito** | **Prioridade** | **Evolução** | **Novo/Alt** | **Origem (UC / RN / decisão)** | **Justificação** | **Critério de aceitação / verificação** |
|---|---|---|---|---|---|---|---|
| **REQ-VID-DOWNLOAD-001** | O sistema deve permitir ao utilizador registado ou premium com permissão de leitura, edição ou de proprietário no projeto descarregar qualquer recurso de vídeo do projeto, original ou resultante. | Deve ter | Novo | NOVO | UC-VID-006 (Passos 1-2, FA4, RN1, RN7, DQ-023) | Permite utilizar fora da plataforma os resultados das operações de vídeo. | Dado um utilizador com permissão de leitura num projeto partilhado, Quando escolhe "Descarregar" num vídeo concluído, Então o sistema inicia o descarregamento do ficheiro. |
| **REQ-VID-DOWNLOAD-002** | O sistema deve gerar, para cada pedido de descarregamento, um URL assinado temporário com validade de 15 minutos associado ao utilizador e ao recurso. | Deve ter | Novo | ALT | UC-VID-006 (Passo 2, Exceção 3, RN4, REQ-VID-NFR-001) | Reutiliza o armazenamento de objetos existente sem expor ficheiros a terceiros. | Dado um URL de descarregamento gerado para o utilizador A, Quando é usado pelo utilizador B ou após 16 minutos, Então o armazenamento responde HTTP 403 Forbidden. |
| **REQ-VID-DOWNLOAD-003** | O sistema deve disponibilizar o descarregamento apenas para recursos de vídeo no estado `completed`. | Deve ter | Novo | NOVO | UC-VID-006 (Exceção 1, RN3) | Impede a obtenção de ficheiros incompletos ou corrompidos. | Dado um vídeo resultante no estado `processing`, Quando o utilizador abre o menu do recurso, Então a opção "Descarregar" está desativada com indicação `RESOURCE_NOT_READY`. |
| **REQ-VID-DOWNLOAD-004** | O sistema deve permitir o descarregamento de vídeos sem debitar qualquer crédito da quota diária do utilizador. | Deve ter | Novo | NOVO | UC-VID-006 (Passo 2, RN2, DQ-014) | O descarregamento não consome capacidade de processamento. | Dado um utilizador registado com 3 créditos, Quando descarrega dois vídeos, Então o saldo da quota diária mantém-se em 3 créditos. |
| **REQ-VID-DOWNLOAD-005** | O sistema deve sugerir um nome de ficheiro composto pelo nome original, um sufixo com a(s) operação(ões) aplicada(s) e a extensão do formato armazenado. | Deveria ter | Novo | NOVO | UC-VID-006 (Passo 3, RN5) | Facilita a identificação do ficheiro no dispositivo do utilizador. | Dado o resultado do recorte de `ferias.mp4`, Quando é descarregado, Então o nome sugerido é `ferias_trim.mp4`. |
| **REQ-VID-DOWNLOAD-006** | O sistema deve entregar o ficheiro no formato em que se encontra armazenado e nunca a cópia de pré-visualização MP4. | Deve ter | Novo | NOVO | UC-VID-006 (FA4, RN7, DQ-012) | Garante que o utilizador obtém o ficheiro original ou o resultado exato da operação. | Dado um original carregado em AVI, Quando é descarregado, Então o ficheiro recebido tem extensão `.avi` e é idêntico (hash) ao ficheiro carregado. |
| **REQ-VID-DOWNLOAD-007** | O sistema deve suportar a retoma de transferências interrompidas através de pedidos HTTP `Range`, enquanto o URL assinado estiver válido. | Deveria ter | Novo | ALT | UC-VID-006 (FA2, REQ-VID-NFR-016) | Evita recomeçar transferências de ficheiros grandes (até 2 GB) após falhas de rede. | Dado um descarregamento interrompido aos 60%, Quando o navegador repete o pedido com cabeçalho `Range`, Então o armazenamento responde HTTP 206 com os bytes em falta. |
| **REQ-VID-DOWNLOAD-008** | O sistema deve gerar um novo URL assinado sempre que o utilizador repete o pedido de descarregamento após a expiração do anterior. | Deveria ter | Novo | NOVO | UC-VID-006 (FA3) | Permite concluir o descarregamento sem intervenção técnica após a expiração. | Dado um URL expirado, Quando o utilizador volta a escolher "Descarregar", Então é gerado um URL novo e válido por 15 minutos. |
| **REQ-VID-DOWNLOAD-009** | O sistema deve registar cada descarregamento nos logs internos com o `correlationId`, o utilizador e o recurso. | Deveria ter | Novo | NOVO | UC-VID-006 (Passo 4, Exceção 4, REQ-VID-NFR-002) | Permite auditoria de acessos e diagnóstico de falhas de entrega. | Dado um descarregamento concluído, Quando consultados os logs centrais, Então existe um evento com `correlationId`, identificador do utilizador e do recurso. |
