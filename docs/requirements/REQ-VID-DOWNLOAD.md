# Requisitos de vídeo — DOWNLOAD

Catálogo do relatório de entrega; IDs e critérios preservados. O estado de refinamento distingue alterações da formulação. O estado da implementação e os resultados estão nas Secções 7.3 e 10 do relatório.

| ID | Requisito | Prioridade | Novo/Alt | Origem | Justificação | Critério de aceitação | Refinamento |

| REQ-VID-DOWNLOAD-001 | O sistema deve permitir ao utilizador registado ou premium com permissão de leitura, edição ou de proprietário no projeto descarregar qualquer recurso de vídeo do projeto, original ou resultante. | Deve ter | NOVO | UC-VID-005 (Passos 1-2, FA4, RN1, RN7, DQ-022) | Permite utilizar fora da plataforma os resultados das operações de vídeo. | Dado um utilizador com permissão de leitura num projeto partilhado, Quando escolhe "Descarregar" num vídeo concluído, Então o sistema inicia o descarregamento do ficheiro. | Inalterado |
| REQ-VID-DOWNLOAD-002 | O sistema deve gerar, para cada pedido de descarregamento, um URL assinado temporário com validade de 15 minutos para o recurso, emitido após autorizar o utilizador; a transferência usa a assinatura portadora do URL e não exige um segundo JWT. | Deve ter | ALT | UC-VID-005 (Passo 2, Exceção 3, RN4, REQ-VID-NFR-001) | Reutiliza o armazenamento de objetos existente sem expor ficheiros a terceiros. | Dado um URL de descarregamento gerado para o utilizador A, Quando é usado pelo utilizador B ou após 16 minutos, Então o armazenamento responde HTTP 403 Forbidden. | Refinado |
| REQ-VID-DOWNLOAD-003 | O sistema deve disponibilizar o descarregamento apenas para recursos de vídeo no estado completed. | Deve ter | NOVO | UC-VID-005 (Exceção 1, RN3) | Impede a obtenção de ficheiros incompletos ou corrompidos. | Dado um vídeo resultante no estado processing, Quando o utilizador abre o menu do recurso, Então a opção "Descarregar" está desativada com indicação RESOURCE_NOT_READY. | Inalterado |
| REQ-VID-DOWNLOAD-004 | O sistema deve permitir o descarregamento de vídeos sem debitar qualquer crédito da quota diária do utilizador. | Deve ter | NOVO | UC-VID-005 (Passo 2, RN2, DQ-013) | O descarregamento não consome capacidade de processamento. | Dado um utilizador registado com 3 créditos, Quando descarrega dois vídeos, Então o saldo da quota diária mantém-se em 3 créditos. | Inalterado |

| REQ-VID-DOWNLOAD-008 | O sistema deve gerar um novo URL assinado sempre que o utilizador repete o pedido de descarregamento após a expiração do anterior. | Deveria ter | NOVO | UC-VID-005 (FA3) | Permite concluir o descarregamento sem intervenção técnica após a expiração. | Dado um URL expirado, Quando o utilizador volta a escolher "Descarregar", Então é gerado um URL novo e válido por 15 minutos. | Inalterado |
